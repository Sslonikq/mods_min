## Что сделано
- **Major 1.** `DungeonMech.sealWanted(spawned, cleared, hall, inside)`: печать закрыта, только пока в коробке зала стоит живой игрок (`Dungeons.hallOccupied`). Погиб и возродился у жаровни: в зале никого, дверь открыта. Залы с печатью (`Def.sealed`) сбрасываются по залу: `LAST_HALL` по тегу зала, `Dungeons.hallStale` через 600 тиков без игрока в зале, даже если игрок жив в данже. Остальные залы сбрасываются как раньше (по данжу).
- **Major 2.** `Rec.layout` (NBT `layout`, нет поля -> `""`). `Def.signature()` = имена частей + хеш размеров, палитры и блоков. `DungeonData.checkLayouts()` вызывается в `load`: при несовпадении `reset(rec)` обнуляет `partsDone/hallsSpawned/hallsCleared/opened/mirrors` и удаляет `respawn`-записи данжа; Разлом строится заново на том же месте. Новые записи (`register`) получают подпись сразу.
- **Major 3.** `Dungeons.Mask`: точный `BitSet` по рамке (клетки шаблонов + коробки залов `y..y+sy` + коробки всех меток; Разлом 499 200 клеток из 2 541 891, 19%) и грубая сетка колонн 16×16 с диапазоном высот. `Rec.contains`: рамка-предфильтр, затем pad 0 — клетка, 1–2 — куб, больше — грубая сетка. `Shield` проверяет рамку, затем маску (рамка из 9 чисел, последние три — начало данжа; конструктор из 6-элементных рамок остался, без маски). Через маску идут `at/inside/near`, элитры, ведро, спавн, взрывы, телепорты, запрет палочек, `purgeFalling` (запрос по рамке с фильтром `contains(...,2)`), `removeStrays` (грубо, pad 24), механики (pad 24). Обычные Rec/Shield-вызовы менять не пришлось.

## Решения и почему
- Точная маска, а не грубая: 320 КБ на Def, строится один раз при первом обращении к шаблонам (≈0,5 млн `add`), проверка — одно обращение к `BitSet`. Грубая сетка добавлена только для запасов >2 (кубический перебор 49³ на моба был бы дорог).
- Воздух залов и меток входит в маску явно (коробки), иначе игрок внутри зала считался бы вне данжа и мог ставить блоки в пустом воздухе. Тест проверяет коробки залов и проходимые клетки под землёй.
- Сброс зала с печатью по залу, а остальных по данжу: сброс по залу для всех изменил бы поведение обычных залов (недобитые исчезали бы, пока игрок гуляет по соседним).
- Подпись включает содержимое блоков: любая правка шаблона генератором сбрасывает прогресс существующих миров на этом данже. Для разработки это приемлемо, но после релиза менять шаблоны надо осознанно (так задумано как «версия шаблона»).
- Не стал вести обход `settle` только по клеткам оболочки, вычисленным заранее в генераторе: с `BitSet` проверка соседей дешёвая, цена снижена до 1/4 единицы на клетку.

## Проблемы и открытые вопросы
- `setSpawnCancelled` по-прежнему не сверен с jar Forge (его нет в проекте); теперь падение невозможно, но при отсутствии метода работает только запасной `setCanceled`. Сверить при первой Gradle-сборке.
- Маска не защищает природные блоки между стен данжа и поверхностью. Если нужно иначе, можно добавить в маску слой над потолками.
- `arcane_helmet.json` и `arcane_leggings.json` по-прежнему помечены `M` из-за окончаний строк, в коммиты не включать.
- Процесс: отчёт `build-engineer` по заглушкам Forge ещё не сделан (п. 9 ревью).
