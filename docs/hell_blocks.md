# Блоки Ада (фаза 5.1)

Источник: `docs/world.md` «Мир Ада: облик, биомы, блоки», картинка `docs/concepts/hell_blocks.png`. Ресурсы генерирует `tools/gen_hell_blocks.py` (текстуры, blockstates, модели, лут, рецепты, теги, lang); Java-часть (регистрация, поведение) — `mod-engineer`.
Блоков 34 (в world.md цифра 32 была приблизительной). Ванильные блоки (лава, магма, песок/почва душ, костяной блок, огонь душ) не создаются.
modId `explosionwand`, ID блока = ID предмета-блока. Все блоки — также предметы (BlockItem, во вкладку «Магия» по усмотрению).

## Рецепты
- `charred_planks`: 1 `charred_log` -> 4 `charred_planks` (shapeless, `recipes/charred_planks.json`).
- `smoldering_planks`: 1 `smoldering_log` -> 4 `smoldering_planks`.
- Палки — обычные (из любых досок через тег `minecraft:planks`, в который добавлены обе доски), верстак тоже. Лестниц и плит нет.

## Теги (в `data/minecraft/tags/`)
- blocks/items `logs`, `planks`, `leaves`, `flowers`.
- blocks `mineable/{pickaxe,axe,shovel,hoe}` (файл `pickaxe.json` дополнен, прежние `seal_stone`, `phoenix_embers` сохранены), `needs_stone_tool` (руда кровавого железа, затменный камень, раскалённый камень), `needs_iron_tool` (самоцвет короны).
- Внимание: `tools/gen_hell_assets.py` пишет `pickaxe.json` целиком (затрёт добавления). Запуск `gen_hell_blocks.py` после него возвращает всё обратно.

## Свойства блоков, нужные Java
- `log`: `axis` (x/y/z). `layer`: `layers` 1-8. `bush`: `age` 0-3. `cluster`: `age` 0-3 и `facing` (6 сторон).
- Блокстейты и модели готовы именно под эти имена свойств.
- Модели-кресты и кусты используют `render_type` cutout, листва — `cutout_mipped`. Ковры — `minecraft:block/carpet`.
