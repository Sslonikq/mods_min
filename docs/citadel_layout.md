# Цитадель Затмения: контракт построек для mod-engineer (фаза 5.3)

Файл генерирует `tools/gen_citadel.py` (`python tools/gen_citadel.py` пишет шаблоны и этот документ; `--check` сверяет и проверяет проходимость; `--preview` рисует `build/citadel_*.png`). **Не править руками**: при изменении координат всё перегенерируется. Источник замысла: `docs/world.md`, «Данж 1 Ада», картинка `docs/concepts/citadel.png`.

Здесь только постройка и метки. Механики (свет и тьма, лампы, маяки, часы, испытания башен, дверь по предметам, спавн, арена Короля) делает код по меткам из раздела «Метки».

## Система координат и размеры
- Координаты данжа **(0,0,0) = ось горы на уровне подошвы**: `y=0` - первый воздух над ровной землёй у подножия, `x` - на восток, `z` - на юг. Все координаты ниже именно в этой системе (как у Разлома, Города и Святилища: код сдвигает их на точку данжа).
- Габарит шаблонов: x -116..116, z -116..116, y -7..82 (233×233×~90). Вокруг горы нужен свободный круг радиуса ~118 блоков.
- Подошва (y -7..-1) залита сплошным `blackstone` на круге r<=115 - карверы и рельеф Базальтовых пиков её не подрежут. Гора - сплошной массив (внутри только комнаты, ходы, шахта, пустота).
- **Что должен сделать код перед вставкой:** расчистить воздухом цилиндр r<=116, y 0..~120 (шпили Базальтовых пиков и деревья), потому что воздух вне комнат в шаблон не записан (шаблон хранит только твёрдые блоки и воздух комнат/ходов). Над Тронным двором нужно ≥55 блоков свободного неба (y>=64) - расчистка до y~125 это даёт.
- Блоки: только ваниль (`minecraft:*`: чёрный камень и его кирпичи, базальт, слёзный обсидиан, золото, слизь, лава, морской фонарь, аметист и т.д.). Блоков мода в шаблонах нет; при желании код может подменить при вставке `blackstone`→`explosionwand:eclipse_stone`, `polished_blackstone_bricks`→`explosionwand:eclipse_bricks` (для этого `Dungeons.state` должен принимать пространство имён мода).
- **Объём: 1 485 126 блоков** (в 6 частях  см. ниже). Парсер `Nbt` в `DungeonTemplate.parse` строит Map на каждый блок - для такой структуры нужен потоковый разбор в массивы или хотя бы пофайловая загрузка с освобождением памяти (часть = ~250 тыс. блоков, файл ~0,65 МБ). Установка в мир - порциями по тикам, как у Разлома.

## Метки (что ставит шаблон, что делает код)

Формат тот же, что у Разлома/Святилища: `t`, `a`, `p` (в координатах части), `s`. Прежние типы работают как раньше (`start`, `door`, `brazier`, `hall`, `chest`, `boss`, `seal`, `lever`, `secret`). Новые типы Цитадели (код сам решает, как их обрабатывать; неизвестные типы `Def.index` просто складывает в `byType`):

| Метка | a | Что стоит в шаблоне | Что делает код |
|---|---|---|---|
| `lamp` | id (`galleryN`, `barracksN`, `hallN`, `towerN`, `dungeonN`, ...) | на блоке-заглушке `amethyst_cluster[facing=up]` на пьедестале `polished_blackstone` (метка на заглушке) | заменяет заглушку Кристальной лампой (ПКМ - свет r~8) |
| `beacon` | 1..3 | `soul_campfire[lit=false]` на дне чаши | зажигает по ПКМ; 3 из 3 - открывает `gate2` |
| `moon_socket` | 1..3 | постамент (`chiseled_polished_blackstone`), метка над ним (воздух) | принимает Лунный камень; 3 из 3 - открывает `prethrone` |
| `moonstone` | 1..3 | пьедестал и `crying_obsidian` на крыше башни, метка над ним (воздух) | выдаёт камень после испытания |
| `sun_src`, `sun_mirror`, `sun_plate` | `sun` / номер / `номер,сторона` | `amethyst_block` (источник и зеркала), плиты-печати из `gold_block` в полу | головоломка Солнечных часов (см. выше) |
| `wave` | зона (`sundial`, `towerN`, `hall`) | воздух, с полом | точки появления волн мобов |
| `mob` | вид: `archer`, `ballista`, `eater` (Пожиратель света), `eye` (Око), `moth` (Мотылёк-гаситель), `jelly` (Лунная медуза), `serpent` (Теневой змей), `colossus`, `prisoner` | воздух с полом | **не `spawn`**: мобов Цитадели ещё нет (5.4), метки пока не обрабатываются; ванильного спавна нет |
| `note` | `archmage` | `lectern` | записка, текст - код |
| `door` | `gate1`, `gate2`, `sun_e`, `sun_w`, `prethrone`, `throne_seal` | сплошной блок (`chiseled_polished_blackstone` + золотая жила) | убирает по условию (осколок, маяки, часы, 3 камня, Печать Трона) |

## Проверки (tools/gen_citadel.py --check)
- все ID блоков есть в реестре 1.20.1; метки `chest`/`boss` по одной в зале, на воздухе, с полом;
- физическая проходимость (`tools/citadel_walk.py`): четверти блока и полублоки; подъём без прыжка только на ступень/плиту (0,5), на блок - прыжок; ступень проходима снизу вверх только со стороны низкой части (`facing` = направление подъёма); потолок над головой не меньше 2 блоков; спуск до 3 блоков; прыжок через разрыв до 3 блоков по ровной, до 2 вверх на блок (диагональные прыжки - только в паркуре башни 2 и в провале обсерватории); ладдеры; на слизь можно падать с любой высоты;
- по этапам прохождения (S0 всё закрыто, S1 +ворота 1, S2 +ворота 2, S3 +решётки часов, S4 +Лунные врата, S5 +Печать Трона): нужное достижимо и до него можно дотянуться рукой (луч, 4 блока): ворота, маяки (по ладдеру), лампы, зеркала, печати, сокеты, Лунные камни, трещина оружейной, рычаг сокровищницы, сундуки; закрытое недостижимо, обхода двери нет (и когда закрыта только одна дверь, и когда закрыты печати);
- обратный BFS: из каждого достижимого места есть путь к старту (спуском до 3 блоков), а для упавшего (до 12 блоков) - хотя бы падением; ловушек без выхода внутри стен нет;
- опора для ладдеров, рычагов, ламп, костров; двери и тайники в шаблоне заполнены, печати - пустые; лава не вытекает. Подробный разбор: `python tools/gen_citadel.py --check --audit`.
