# Проверить в игре

Сводный чек-лист того, что нельзя проверить без запуска игры. Ведёт команда `/ingame`:
новые пункты берутся из раздела «Проверить в игре» отчётов, проверенные — вычёркиваются
(`[x]` + дата), сломанное становится замечанием (`/fix` или строка в ROADMAP).
Пункты не удалять, пока пользователь не подтвердил.
