# Баланс боссов Земли (расчёт, 4.13 п.6)

Расчёт по коду, не замер в игре. Цели по времени (Монолит ~2-3 мин, Феникс ~4 мин без лука) - только ориентир "босса реально убить"; **боссов не облегчаем** (решение пользователя). Если бой дольше цели - только отметка и предложение.

## Урон игрока по боссу (на 100% времени, до поправок)
| Источник | Урон | Темп | DPS | Примечание |
|---|---|---|---|---|
| Алмазный меч | 7 | 0,625 с | 11,2 | |
| Незеритовый меч | 8 | 0,625 с | 12,8 | |
| Взрывная палочка | 8 | 1,5 с | 5,3 | луч 48 блоков, по летящему Фениксу тоже |
| Шипы | 5 | 5 с | 1,0 | только по стоящему на земле |
| Искры | 5 (3 искры в одном окне неуязвимости = 1 попадание) | 4 с | 1,25 | наводятся |
| Посох Разлома | 0 | - | 0 | хосты боссов (тег ewd) не затягиваются |
| Посох Сна (кольцо) | 5 / 0,5 с вплотную | 10 с из 20 | ~5 | только вблизи; у Монолита его ещё нет |
| Посох Феникса | 3 | 6 с | 0,5 | у Феникса ещё нет |

Допущения: неуязвимость цели 10 тиков - одновременные источники складываются не полностью, поправка 0,75-0,8; меч достаёт цель 55% времени у Монолита (кольца, луч), у Феникса - только в посадке.

## Монолит Сна (1700 ХП, уязвим всегда, кроме 3 расколов по ~3 с)
Набор: меч + Взрывная + Шипы + Искры (Посоха Сна и Феникса на этом бое ещё нет).
| Набор | Расчёт | Время |
|---|---|---|
| только незеритовый меч | 1700 / (12,8 x 0,55) + 15 с | ~4,3 мин |
| незерит + палочки Земли | 7,0+4,3+0,7+1,0 = 13,0 x 0,8 = 10,4 DPS -> 163 с + 15 | ~3,0 мин |
| алмаз + палочки Земли | 12,2 x 0,8 = 9,8 DPS -> 173 с + 15 | ~3,1 мин |
Вывод: в целях (верхняя граница); не меняли.

## Пепельный Феникс (2000 + яйцо 150 + возрождение 700 / 1500)
Меч достаёт его в посадке: 3 с x1,5 раз в ~14,5 с цикла (22%). Палочки и искры бьют и в полёте.
| Составляющая | DPS |
|---|---|
| меч (незерит) в посадке | 4,2 (алмаз 3,8) |
| Взрывная 80% попаданий | 4,3 |
| Искры | 1,0 |
| Шипы (посадка x1,5) | 0,4 |
| кольцо Посоха Сна (посадка) | 0,5 |
Итого 10,4 x 0,8 = ~8,3 DPS. Фазы 1-2: 2000/8,3 = 241 с; яйцо ~12 с; ослабленное возрождение 700/8,3 = 84 с; переходы ~25 с -> **~6,0 мин** (полное возрождение 1500: ~7,7 мин). Цель ~4 мин **превышена в ~1,5 раза**. По решению пользователя не меняем. Предложение пользователю (не сделано): дать игроку больше урона, а не ослаблять босса - например Взрывная палочка 8 -> 10, либо окно посадки x1,5 -> x2 (боссу не вредит, делает окно наградой). Если оставить как есть, бой без лука ~6 мин, с луком короче.

## Сложность боссов
Ни один параметр боссов в 4.13 не менялся: Монолит и Феникс в целях или дольше цели, то есть не лёгкие. Быстро убивающих босса источников нет: Посох Разлома боссов не бьёт, кольцо Сна и Феникса тоже недоступны к моменту боя, Столп солнца теперь не бьёт ew*-сущностей.

## Столп солнца Посоха Затмения (ревью 0129 nit 9)
Бил любые живые сущности по 6 урона раз в 5 тиков (с учётом неуязвимости ~12 DPS 4 с, до ~48 урона за выстрел), включая хосты боссов данжей. Решено: **пропускать ew*-сущности**, как Луны и Сверхновая (`!Cmd.hasTagPrefix(x, "ew")`). Посох на Земле недоступен, но так он не обходит сопротивление боссов, когда попадёт в руки через творческий режим или Ад.
